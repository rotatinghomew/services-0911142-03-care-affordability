# 现场复核

先在画外完成依赖或镜像准备。服务就绪检查为 `/health`，启动不下载资料。

## 费用浏览

打开首页，在「费用浏览」标签选择收费月份与居住类型，查看挂牌服务成本；从任一明细点开原始记录核对。保存一次当前材料，然后改动选择并重新计算，再打开刚才的记录，确认原范围仍在，最后导出。

## 家庭可负担性试算

切到「家庭可负担性试算」标签：

1. 选择服务口径（observed 样本消费或 uniform 统一服务情景）、负担线、交通费漏报口径；uniform 下可指定统一小时数。需要改服务组合或价格日期时，在收费调整栏填入要改的字段（留空沿用当月收费表），点击「运行试算」。
2. 查看超过负担线/低于/不可判断三类家庭的加权比例与自助95%区间、加权CDF区间带，以及各收费与补助条款（含封顶削减额）的加权户均贡献。
3. 在家庭明细点击任一户，底部显示逐账单与家庭层面的完整计算过程；不可判断家庭附原因（收入开区间、交通费漏报、成员关系待确认或区间跨越负担线）。
4. 选择对比情景的月份与服务口径后点击「与对比情景比较」；对比只在相同家庭基础上进行，差值给配对自助区间，条款贡献逐项列出变化金额。
5. 用「保存当前视图」留存试算或对比，存档按浏览/试算/对比分类标记，重新打开不随新数据重算。

上述操作的设计时长为45至90秒，留出异常提示时间后不超过120秒。部署故障不隐藏也不回放旧结果。试算结果是区间、分类与不确定性，不输出档位中点构造的精确排名；新增分析的实际结果和可操作性须在功能完成后重新验证，不限定显著性或结论方向。
